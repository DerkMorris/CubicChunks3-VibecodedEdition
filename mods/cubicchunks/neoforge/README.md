# NeoForge

Адаптер для Minecraft 26.3 / NeoForge 26.3.0.101, JDK 25. Сборка: `:cubicchunks:neoforge:build`.
`runClient` и `runServer` используют отдельные каталоги `run/neoforge`.
Установочный JAR включает DASM и Core. Общая логика компилируется из `../common`.
Задача `test` загружает настоящий FML, проверяет регистрацию мода, сервисы, сериализатор, создаёт кубический мир и сохраняет изменения блоков на высотах ±32 млн.
В `legacy` сохранены исторические исходники, исключённые из сборки.
