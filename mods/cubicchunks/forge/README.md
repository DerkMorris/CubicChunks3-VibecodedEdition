# Forge

Будущий адаптер CubicChunks для Forge. Подключение в Gradle начинается с добавления build.gradle.
Потребуются реализации Platform и ClientPlatform, регистрация пакетов и сериализаторов, события клиента,
метаданные загрузчика и доступ к Minecraft-классам. Общая реализация находится в соседнем каталоге common.
